# Hand-written NuGet version ranges, one per line, from the version range examples of the NuGet
# package versioning documentation and the cases of VersionRangeFactory.TryParse. Each is parsed with
# VersionRange.TryParse (without floating versions) and checked with VersionRange.Satisfies against
# every version in nuget.txt. generate.ts trims each line, so a range that needs leading, trailing or
# invisible whitespace is written as a JSON string (a line starting with `"`), which the oracle
# decodes and the tests read back with the same rule. Version lines cannot hold whitespace, so NuGet's
# whitespace handling in versions is exercised through range bounds (`1 . 0`, `1.0\u0085`).
