## Unreleased

## v0.3.0

FEATURES:

- Scheme `golang`, matching `golang.org/x/mod/semver` v0.42.0, including pseudo-versions and
  `+incompatible`. The `v` prefix is optional, so `1.2.3` equals `v1.2.3`.

## v0.2.0

FEATURES:

- Scheme `maven`, matching `ComparableVersion` from Maven 4.0.0-rc-7, and `fromNative` for Maven
  version ranges such as `[1.0,2.0)` and `(,1.0],[1.2,)`.

## v0.1.1

NOTES:

- The README no longer says polyver is unpublished, and it now covers installation and how to verify
  provenance.
- Releases are now published from GitHub Actions through npm trusted publishing, with provenance. v0.1.0
  was published by hand and has no provenance.

## v0.1.0

FEATURES:

- VERS core following vers-spec Clause 5: `parseVers` (strict), `normalizeVers` (repairs non-canonical
  input), `stringifyVers` and `contains`, with typed `VersError` codes. Containment includes the fix
  for single-bound ranges ([vers-spec#54](https://github.com/package-url/vers-spec/issues/54)).
- Schemes `semver`, `npm`, `pypi` (PEP 440), `intdot`, `lexicographic`, `datetime`, `all` and `none`.
- Schemes `deb` (matches dpkg), `rpm` (matches rpm's EVR comparison, including `~` and `^`) and `apk`
  (matches apk-tools 3), tested against vectors generated by running those tools.
- `fromNative` converts npm ranges and PEP 440 specifiers to canonical VERS, merging overlapping
  alternatives.

NOTES:

- The package includes `THIRD_PARTY_NOTICES.md` for code adapted from pypa/packaging, node-semver and
  osv-scalibr.
