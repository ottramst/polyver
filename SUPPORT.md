# Support

- **Questions and usage help:** ask in [GitHub Discussions](https://github.com/ottramst/polyver/discussions).
- **Bugs and feature requests:** open an [issue](https://github.com/ottramst/polyver/issues/new/choose) using one of the templates.
- **Security vulnerabilities:** see [SECURITY.md](SECURITY.md); do not open a public issue.

This library is maintained on a best-effort basis by volunteers.
